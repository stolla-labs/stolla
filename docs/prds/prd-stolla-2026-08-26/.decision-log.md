# Decision Log — Stolla Self-Serve Governance Pilot

## 2026-08-26

- **Decision:** Create a new PRD that supersedes `docs/prd.md` instead of editing the stale v0.1 document in place.
  - **Rationale:** The repository already implements multi-community capabilities that v0.1 explicitly marked out of scope.
- **Decision:** Focus the sprint on one coherent, testnet, multi-community journey.
  - **Rationale:** Route, registry, wizard, event, and configuration duplication currently fragments working capabilities.
- **Decision:** Keep CommunityFactory owner-only during this sprint and add authorization preflight.
  - **Rationale:** Changing the on-chain creation policy is a product/security decision that conflicts with the requested low-complexity issue shape.
- **Decision:** Defer timelock, treasury execution, mainnet, and a hosted indexer.
  - **Rationale:** These require deeper security and operational work than a low-token implementation sprint supports.
- **Decision:** Create ten wide migration issues and ten normal product issues.
  - **Rationale:** Wide issues must naturally affect at least twenty files through one shared primitive or consolidation, never through filler edits.
- **Decision:** Write all GitHub-facing content in English.
  - **Rationale:** The repository's contributor-facing language is English.
- **Decision:** Treat the current red frontend checks as an explicit sprint gate.
  - **Evidence:** On 2026-08-26, lint reported 3 errors, typecheck reported 9 errors, and Vitest reported 29 failed tests.
- **Decision:** Use a normative four-state Proposal freshness model for the pilot.
  - **Rationale:** RPC-derived history must distinguish current, delayed, stale/partial, and unavailable results without pretending to offer an indexer SLA.
- **Decision:** Encode Proposal Metadata as a bounded, deterministic versioned JSON envelope in the existing Governor description field.
  - **Rationale:** This improves authoring without a contract change and preserves safe rendering for legacy free text.
- **Decision:** Close all ten pre-sprint open PRs (#233–#242).
  - **Rationale:** They were stale draft fixes or repetitive incompatible documentation/CI changes and none had green checks.

## Deferred decisions

- Community creation policy after the testnet pilot.
- Persistent indexer trigger and operating model.
- Product role or removal of the price-oracle contract.
